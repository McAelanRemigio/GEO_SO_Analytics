### 1. Study Abroad Analytics Engine
**Python | Pandas | Data Validation | Data Analysis**

An independent Python package designed to process, clean, validate, and analyze exported Study Abroad reports.

**Key features:**
- Import CSV and Excel reports.
- Clean and standardize column names and values.
- Filter, search, sort, and organize datasets.
- Validate missing values, duplicate records, and data types.
- Analyze participation by college, major, country, program type, and academic year.
- Calculate student participation and GPA summaries.

**Goal:** Build a reusable analytics framework that can independently process exported Study Abroad data without relying entirely on the original reporting platform.

**Status:** In development.
